# 달성On 프로토타입 (달성군 AI 업무비서 · 시연판)

부군수 보고용 시연 프로토타입. **직원용(달성On)** 과 **군민용(카카오 채널)** 두 채널을 화면 상단 스위치로 오가며
기능 범위를 눈으로 확인하도록 만든 정적 웹앱입니다. 서버 없이 Netlify(또는 GitHub Pages)에 그대로 올라갑니다.

## 폴더 구성
```
site/                 ← Netlify 배포 폴더 (이 폴더만 올리면 됨)
  index.html          화면 구조
  style.css           스타일
  app.js              검색(BM25) · 답변 모델 호출 · 카카오 목업 · 관리자 화면
  hwpx.js             브라우저에서 한글(hwpx) 파일 생성 (JSZip)
  hwpx_tpl.json       달성군 표준 서식 hwpx의 스타일·서식 템플릿 (그림·미리보기 제거본, 230KB)
  vendor/jszip.min.js 압축 라이브러리 (폐쇄망 대비 로컬 포함)
  data/index.json     자료 색인 1,146건 (아래 build_data.py 산출물)
data/                 원천 자료
  law/*.txt           2026.7.10 공포 조례·규칙 7건 (hwpx→txt)
  *.csv               공공데이터 6종 (경로당·종량제판매소·도서관·무료급식소·대형폐기물수수료·봉투가격)
  minwon.json         민원 안내 10건 ★예시(홈페이지 기준으로 수기 작성 — 실제 운영 전 검수 필요)
  internal.json       내부지침 5건 ★예시(직원 전용 층 시연용 — 실제 지침 아님)
build_data.py         data/ → site/data/index.json 색인 생성
kakao_skill/app.py    (선택) 카카오 i 오픈빌더 스킬 서버 — 실제 카카오톡 연동 시 Render 등에 배포
```

## 배포 (Netlify)
1. 이 폴더를 GitHub 저장소로 push
2. Netlify → Add new site → Import from Git → **Publish directory: `site`**, Build command: 비움
3. 배포 URL 접속 → 우상단 ⚙ 설정에 Anthropic API 키 입력(브라우저 메모리에만 보관, 저장·전송 안 함)
   - 키 없이도 **오프라인 시연 모드**(검색 결과 기반 답변)로 전 기능 동작 → 폐쇄망 시연 가능
   - 로컬 확인: `cd site && python -m http.server 8080` 후 http://localhost:8080

## 시연 시나리오 (5분)
| 순서 | 화면 | 보여줄 것 |
|---|---|---|
| 1 | 직원용 | "거리공연 지원사업 내용과 조례 근거는?" → 조문 인용 [1][2] + 우측 근거 카드 |
| 2 | 직원용 | "다사읍 경로당은 몇 개소야?" → 공공데이터 집계(66개소) |
| 3 | 직원용 | "연가 2일 신청하면 결재선이?" → 🔒 내부지침(직원 전용 층) |
| 4 | 직원용 | **[한글 파일 생성]** → 달성군 서식 hwpx 다운로드 → 한글에서 열기 ★차별점 |
| 5 | 군민용 | 스위치 전환 → 카카오 화면 "대형폐기물은 어떻게 버려요?" → 절차·수수료 + 접수 링크 |
| 6 | 관리자 | 📊 이용통계 · 자료 갱신 한 번 → 전 직원 반영 |

## 실제 구축 시 달라지는 점
- 검색·모델 호출을 **업무망 자체 서버**로 이동(브라우저에 키 없음), 모델은 서버 내 모델 또는 행안부 온AI API(개방 시)
- 자료: 1층 공개자료(자동 수집) → 2층 내부지침(부서 협조) → 3층 공문서(2단계, 권한체계)
- 군민 채널: `kakao_skill/app.py` 를 카카오 i 오픈빌더 스킬로 등록 (공개자료만 참조)

## 자료 갱신
```
python build_data.py      # data/ 수정 후 실행 → site/data/index.json 재생성
```
